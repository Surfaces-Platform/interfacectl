interfacectl

This Vercel deployment is a lightweight landing page for the shared `interfacectl` monorepo. The repo itself ships CLI and validator packages, so previews stay repo-scoped and defer product onboarding to the primary interfacectl website.

  • Primary Website Install instructions, onboarding, and the public product surface.
  • Repository Source, release history, and pull requests.
  • README Setup, workflow, and command overview.
  • API Reference CLI commands, contract semantics, and extraction notes.
  • Contract Baseline Minimal authoritative contract shape and policy surface.
Preview deployments are intentionally static for this repository and are not the primary product site.
